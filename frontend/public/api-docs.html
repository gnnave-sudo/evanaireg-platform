Call Flow Diagrams

Flow 1: NL Query → Procedure

User: "What AML filings are due?"
  ↓
POST /v1/nl/query { "query": "What AML filings are due?", "entity_slug": "vortex-pay" }
  ↓
[Keyword: "filing", "due" matches intent "deadlines"]
  ↓
→ PROC-001 triggered → RIE Agent → entity_manager.get_obligations() → DeadlineResponse
  ↓
{ "procedure_triggered": "PROC-001", "response": "Found 2 critical obligations...", "confidence": 0.92 }

Flow 2: TX Ingest → Threshold Breach

POST /v1/tx/ingest { "tx_id": "TX-001", "amount": 50000, "fee_type": "FX Fee" }
  ↓
TMA Agent → entity_manager.get_thresholds(entity_id, "MEX")
  → PLD Single Transaction = 21890.40 MXN
  → 50000 ≥ 21890.40 = BREACHED
  ↓
{ "threshold_flag": true, "status": "flagged", "threshold_reason": "..." }
  ↓
Auto: db.log_risk_event(entity_id, "THRESHOLD", "HIGH", ...)

Flow 3: New Client Onboarding

POST /v1/entities { "slug": "acme-corp", "name": "Acme Corp" }
  ↓
EntityManager.create_entity() → entity_id = 3
  ↓
(Direct DB or future API)
  create_jurisdiction("USA", "United States")
  create_threshold("BSA Reporting", 10000, "USD", entity_id=3)
  create_obligation("FINCEN-001", "CTR Report", ..., entity_id=3)
  create_rule("NO-ANON", "No Anonymous Accounts", ..., entity_id=3)
  ↓
evan query -e acme-corp "What filings are due?" → Acme Corp's data only
